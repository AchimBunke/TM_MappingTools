Info

Trigger Item Variant Creator (Gate Variant Creator)

Source Code: Gate Variant Creator Github

This tool is a C# implementation of Custom Gates (GitHub) by schadocalex.

Item Requirements for Blender
  • _trigger_ objects define the zone where the gameplay takes effect.
  • Materials are resolved via their Link, so use TriggerFX, SpecialFX, Sign, SignOff, or Decal links. The material name and the effect of the link (Turbo, Boost, etc.) do not matter.
  • Export the item as usual.
  • Drag and drop it onto the exe file to create all available effect variants as a zip file.
Notes
  • No guarantee it will work with all items. There is currently a problem with parsing items with trigger effects in GBX.NET.
  • Not all effects have icons, decals, signs, and TriggerFX. For those, either a default one or a texture from another effect is used.
